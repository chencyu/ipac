# Semantic Distillation

A body of content is a set of statements, each written locally: for one moment, incident, or reader. Distillation replaces those statements with the smallest model that generates them, then converges the body onto that model. Run `skill: thinking-principles` with the body as the observation set; this skill adds what statements, unlike phenomena, require.

1. **Separate grounds, anticipations, and observations.** Stated requirements, measured facts, and external decisions cannot be derived; carry them through unchanged. A provision written for a case that never occurred records nothing; unless a ground or observation backs it, it drops out. Everything else records what happened and is observation the core must regenerate.
2. **Weight the observations.** Corrections show where a default diverged from what the domain requires; abandoned approaches show what the core must exclude. Both outweigh statements that merely repeat.
3. **Converge by derivation.** Remove a statement only once its reader re-derives it from the core. A statement the reader cannot re-derive calls for revising the core first; it stays only if no revision lets the reader derive it.
4. **Place the result.** The core gets one authoritative home where its reader meets it, per `skill: design-principles`, written by `skill: semantic-writing`; other occurrences reference it.

Test the result twice. Generativity: a reader holding only the result, who has never seen the source, arrives at every corrected behaviour and every removed statement. Fecundity: apply the result to a case the source never raised; if it yields nothing, it summarises the source instead of governing the domain.

A result that narrates what happened is not distilled; one whose statements hold in any domain is not distilled either. The right abstraction level is the highest at which the core still forces specific behaviour.
